# Agent orientation

Repository specifics for agents working in ghostclauf. `AGENTS.md` carries the
policy. This file carries the project detail that the policy points to.

ghostclauf is a plugin-based Twitch chat bot. Node 20+, TypeScript, ESM.

## Commands

- Install: `npm install`. Build: `npm run build`. Dev: `npm run dev`.
- Test all: `npm test` (vitest run).
- Single test: `npx vitest run test/<file>.test.ts` or `npx vitest run -t "<name>"`.
- Typecheck: `npm run typecheck`. Lint: `npm run lint`.
- One-click setup, run, and site publish: `./setup.sh`, `./run.sh`,
  `./publish-site.sh` (`.bat` equivalents on Windows).
- One-time bot OAuth: `npm run auth`. Snapshot export: `npm run export:public`.
- Public site validation: `npm run lint:site` and
  `python scripts/check_public_site.py`.

## Do not touch

- `dist/`: build output, generated by `npm run build`.
- `data/`, or wherever `TOKEN_STORE_PATH` points. Holds live OAuth tokens.
- `node_modules/`.

## Plugin contract

Plugins never import `@twurple/*`. Each plugin receives a `BotContext` and uses only
`ctx.command({...})`, `ctx.on(event, handler)`, `ctx.say(text, replyToId?)`,
`ctx.config`, `ctx.broadcasters`, `ctx.helix`, `ctx.drain()`, and `ctx.logger`,
all defined in `src/core/types.ts`. This is ghostclauf's instance of Rule 6:
`BotContext` is the stable surface and `@twurple` is an internal detail
confined to `src/core/twitch.ts`.

## Public site

`site/` is the sole GitHub Pages artifact. It may contain only public
snapshots and static assets. Never copy `data/`, configuration, token stores,
journals, backups, or logs into it. `src/tools/exportPublicSite.ts` must
allowlist public fields before writing `site/data/public.json`.
